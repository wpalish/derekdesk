# DerekDesk: работа над отдельным продуктом

- Это реализация для референса #1 Botpress. Один продукт не закрывает другие позиции из программы 100.
- Перед продолжением прочитать PRODUCT.md, README.md, docs/acceptance.md и состояние программы в рабочей папке родительского чата: work/program/program-state.json.
- Проверять Git и текущие изменения. Не затирать незавершённую работу другого исполнителя.
- Текущая стадия — доменное ядро. Следующий этап: HTTP API с сессиями и проверкой ролей, затем UI и сквозная проверка. Не заменять это очередным README или лендингом.
- Внутренние материалы, обращения, пользователи и копии не выдаются публичному посетителю. Параметр audience назначается сервером после проверки доступа. Для публичного обращения нужен отдельный защищённый канал чтения.
- Сохранять реальные данные и исходные версии. Не сбрасывать повреждённую или более новую базу автоматически.
- Любые тестовые данные явно вымышленные; базы и секреты не коммитить. Новые расходы не создавать без поручения владельца.
- Не объявлять продукт готовым до браузерного сценария и проверки сохранения. Подтверждённые недостатки конкурента отделять от наших проектных решений и гипотез.
- После рабочего продукта подготовить исследование конкретных компаний СНГ. Сообщения им не отправлять без отдельного поручения.
- Журнал и состояние программы обновлять по фактическому результату. Стадии кода, локальных тестов, размещения, модерации и продаж различать.
