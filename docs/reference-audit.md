# Botpress: проверка публичной функциональности

Дата: 24 октября 2026. Проверены официальные документы; аккаунт и скрытые сценарии Botpress не тестировались. Подтверждённых внутренних дефектов: **0**.

## Что уже есть в референсе

- Русский и казахский есть в [списке поддерживаемых языков](https://botpress.com/docs/studio/guides/advanced/additional-information/languages/); перевод и смена языка описаны в [Translator Agent](https://botpress.com/docs/studio/concepts/agents/translator-agent/).
- [Human Handoff](https://botpress.com/docs/studio/get-started/manage-your-agent/human-handoff/) и [описание механизма](https://botpress.com/features/human-handoff) подтверждают передачу сотруднику с контекстом. Для новых workspace документация направляет в Botpress Desk; старый HITL имеет отдельные условия плана. Не обобщать это условие на все варианты.
- [Источники базы знаний](https://www.botpress.com/docs/learn/reference/knowledge-base/add-sources/) включают сайты, документы и таблицы; переобход сайтов можно настроить. Нельзя утверждать, что Botpress вообще не обновляет знания.
- [Knowledge bases в ADK](https://botpress.com/docs/adk-v1-17/data/knowledge/) описывают ответы с цитатами и источниками. Само наличие цитаты не подтверждает правильность ответа.

## Наши проверяемые решения

Гипотеза продукта: небольшой справочник правил компании, где человек утверждает конкретные ответы на RU/KK, материал имеет срок актуальности, а отсутствие уверенного тематического соответствия ведёт в очередь сотруднику. Начальная реализация без LLM и платных внешних API, с SQLite в собственной инфраструктуре.

Это выбор объёма и способа реализации, а не доказательство отсутствия аналогичных настроек у Botpress. Для заявления о преимуществе потребуются сравнительные сценарии, реалистичный корпус вопросов и проверка результатов человеком.

## Риски гипотезы

- Сопоставление формулировок по правилам имеет ограниченное покрытие: перефразированный вопрос может попасть сотруднику. Нельзя обещать качество смыслового поиска.
- Политики и переводы должен подтвердить владелец материала. Два языка не означают автоматически правильный перевод.
- Доменное разделение public/staff не заменяет серверную авторизацию. Защита API ещё впереди.
- Полная платформа Botpress шире: этот проект пока не замена конструктору, интеграциям и облачной эксплуатации.

Поиск конкретных компаний начнётся после сквозной проверки приложения. Текущие результаты — 13 автоматических тестов ядра; реальных клиентов, внедрений и выручки нет.
