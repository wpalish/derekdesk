# DerekDesk 0.1

Самостоятельно размещаемое веб-приложение для узкого процесса поддержки: **утверждённый ответ RU/KK → источник и срок → передача сотруднику → ответ посетителю**. Собственный код; Botpress служит референсом категории. Полное соответствие Botpress не заявляется.

## Запуск

Нужен Node.js **24.15–24.x**. Внешних npm-зависимостей нет.

1. Установите `DESK_ADMIN_USER` (по умолчанию `admin`) и секретную переменную `DESK_ADMIN_PASSWORD` с собственным паролем от 14 символов. Пароль создаёт первого администратора только в пустой базе. Не помещайте его в Git.
2. Выполните `npm test`, затем `npm start`.
3. Откройте `http://127.0.0.1:8791/`, войдите в кабинет, создайте материал и отдельно одобрите его.

По умолчанию сервер слушает только `127.0.0.1`, SQLite хранится в `.data/desk.sqlite`. Параметры: `DATABASE_PATH`, `PORT`, `HOST`, `PUBLIC_ORIGIN`. Без первоначального пароля сайт не создаёт общий аккаунт. Переменная начального пароля не меняет существующий пароль.

Для доступа по сети нужен собственный сервер и HTTPS-прокси, корректный `PUBLIC_ORIGIN` и защищённые права на каталог данных. Здесь проверен локальный запуск; публичного облачного сервера, проверки нагрузки и внешнего аудита нет. За прокси лимит запросов применяется к адресу прокси; этот выпуск рассчитан на небольшой пилот одной организации.

## Работа

- Администратор создаёт публичный или внутренний материал на RU/KK: точный ответ, явные формулировки вопросов, название/ссылка/фрагмент источника, дата проверки и срок актуальности. Новая запись и правка всегда требуют отдельного одобрения.
- Посетитель выбирает RU/KK и задаёт вопрос. Ответ подбирается по нормализованным фразам, **без LLM и семантического поиска**. Неизвестный, неоднозначный или недоступный по языку ответ передаётся человеку.
- Найденный ответ содержит исходный фрагмент, версию и срок. Посетитель может сам запросить сотрудника. Оператор отвечает в очереди; посетитель проверяет ответ в своей вкладке.
- Администратор создаёт операторов. Оператор отвечает на обращения и читает материалы, но не создаёт аккаунты и не утверждает знания.
- Сессия: HttpOnly/SameSite cookie, срок восемь часов, CSRF и проверка Origin для изменений. Обращения посетителей защищены отдельными случайными ключами: знание UUID не открывает переписку. Публичный клиент не назначает себе staff-доступ.

Ключи обращений хранятся только в `sessionStorage` вкладки. После её закрытия посетитель теряет доступ; восстановления по почте и уведомлений пока нет. Не вводите в пилот пароли, платёжные данные или личные документы. Вопросы и ответы остаются в SQLite владельца сервера; внешних AI-вызовов нет.

## Копии и восстановление

Кабинет администратора экспортирует знания JSON. При импорте весь пакет проверяется до записи, материалы становятся черновиками. Это **не полная копия** переписки и аккаунтов.

Для полной согласованной SQLite-копии, включая WAL, выполните:

```sh
node src/snapshot.js .data/desk.sqlite .data/backup-new.sqlite
```

Существующий файл назначения не перезаписывается. Храните копию закрытой: она содержит переписку и хеши учётных данных. Для восстановления остановите сервер и запустите его с `DATABASE_PATH`, указывающим на восстановленную копию. Исходную базу сохраните. Утилита использует официальный SQLite backup API Node.js.

## Проверено

**22 автоматических теста:** доменная логика, точные RU/KK ответы, сроки и версии, доступ к очереди, роли, CSRF/Origin, доступ только к своему обращению, отзыв сессий, ограничения входа, импорт и восстановление, сохранение при перезапуске, согласованная резервная копия. Чужая или более новая база отклоняется без сброса.

В реальном браузере на синтетических данных пройдено: создание материала → одобрение → русский ответ с источником → запрос сотрудника → ручной ответ → получение посетителем → казахский ответ. Проверены ширины 1440, 1280 и 390 пикселей.

Нет WhatsApp/Telegram/телефонии, конструкторов сложных сценариев, распознавания документов, платежей, многоарендности, автоматического перевода и доказанных результатов клиента. [Проверка референса](docs/reference-audit.md) отделяет известные функции Botpress от наших гипотез.
